# Native tvOS interface preview — 20 October 2026

The original design remains authoritative: colours, fonts, shelf ordering,
poster sizes, themes, sidebar and custom layouts are painted by the existing
core. This is a hybrid migration, not a complete rewrite of every screen in
Swift. It introduces Swift/UIKit controls over the actual layout's interactive
rectangles and native portrait image views beneath the design overlay.

## Navigation

- UIKit manages focus between real controls corresponding to the visible
  posters and buttons. Focus changes call the same validated C focus callbacks
  used by the existing interface. They do not emit arrow keys.
- The SDL parent responder uses UIKit's normal input path while native controls
  own focus. The legacy receiver remains available for playback, internal
  widgets without native targets, the friends shelf, system keyboards and sleep.
- Modal target layers discard background controls. Login, Home, title details,
  search, library, sidebar and settings publish their current preferred focus.
- Unmarked states retain the legacy receiver, preserving the original default
  selection in confirmation dialogs. Inactive native surfaces are hidden so
  they cannot occlude the legacy focus receiver.
- Edge navigation retains the core's scrolling and restores the newly visible
  target. Select down/up preserves long press, and held Select prevents moving
  to another native control. Native activity resets the OLED idle timer.

## Images and stability

- Settled, unfocused portrait posters use UIImageView. Existing badges, labels,
  progress bars and effects remain above them. Focus/reveal animation, spoiler
  blur, expanded cards and trailers retain their original rendering path.
- Native images reuse pixels already decoded by the bounded image workers;
  no second network request or compressed-image decode is added. The additional
  decoded cache has a 32 MiB/64-entry target; visible images survive pressure
  until a complete replacement frame. The original image path handles misses.
- The native poster plane stays directly below the design overlay and above
  newly inserted video planes, so starting a hero trailer cannot cover posters.
- The tvOS drawable requests HiDPI; text and texture sizes follow its actual
  resolution. Texture minification uses trilinear filtering. Undersized TMDB
  variants are promoted to the requested size without changing custom/signed
  CDN hosts. See [TMDB image formats](https://developer.themoviedb.org/docs/image-basics).
- tvOS HTTPS requests now verify TLS peers and hostnames with the bundled
  Mozilla CA roots. `https://dexworld.cc/appletv/` returned HTTP 200 with that
  bundle and successful certificate verification during validation.
- A failed state-directory read no longer wipes the previous mirror. File
  content-read failures retain an existing bounded backup, empty state is preserved, and
  actual payload sizes are rechecked before saving. Unchanged mirrors are not
  rewritten.

## Validation and limits

- Production native input/image files are compiled unchanged by the standalone
  tvOS 26.5 regression host. Eleven UI tests cover native four-direction movement
  without duplicate SDL arrows; offscreen shelves; unmarked-screen selection
  preservation; long Select; system-dialog focus; decoded RGB/alpha behaviour;
  poster/video-plane ordering;
  and the five existing legacy remote regressions.
- Host checks cover remote timing under ASan/UBSan, artwork URL promotion and
  hostile host names, subtitle indexing, subtitle selection and configuration.
- Full arm64 device Release and arm64 simulator builds pass. The complete app
  launches on the simulator and its existing login design was inspected.
- Live catalogue, all personalised layout combinations, streaming and physical
  Siri Remote touchpad feel require a signed-in/device acceptance run. Simulator
  button tests cannot establish physical touchpad behaviour or device FPS.
- Aether remains pinned at 7.40.1 with the previously enabled object-audio
  dependencies. This change does not claim a newer player release.

This preview is deliberately available for device acceptance before promotion
to the stable Latest release. Requires tvOS 26+ and signing the unsigned IPA.
